## 🎨 Choix de direction artistique appliqués

### Palette royale harmonisée (exigée)
| Rôle | Couleur | Hex |
|---|---|---|
| Noir perle (profondeur) | ⬛ | `#0A0A0A` |
| Violet royal (majesté, créativité) | 🟪 | `#6A0DAD` |
| Or impérial (prestige, luxe) | 🟨 | `#FFD700` |
| Blanc diamant (pureté) | ⬜ | `#FFFFFF` |

Le vert n'apparaît que comme **couleur de marque** (icônes WhatsApp) et dans
le **drapeau ivoirien** du footer — jamais dans l'interface. L'orange ivoirien
n'existe que dans ce même drapeau national.

### Harmonisation des visuels
Toutes les affiches sont traitées de manière uniforme : vignette or/noir
identique, contraste et saturation calibrés (filtre CSS commun), légende
**toujours visible sous l'image** (titre + description captivante),
grille rythmée avec visuels pleine hauteur.

### Typographie
- **Montserrat** (400→900) — corps, titres, interface : modernité technologique.
- **Playfair Display** (italique) — accents de prestige (« succès », chiffres,
  bandeau défilant) : élégance 6 étoiles.

### Animations & immersion
1. **Préloader** cinématique (logo rond + barre or/orange).
2. **Slogan animé** « Votre succès commence en ligne » — décodage cybernétique
   (scramble) + mot *succès* en dégradé or → violet **néon pulsant** (or impérial
   ↔ violet royal, Playfair italic).
3. **Particules** or/orange/blanc en canvas dans le hero (pause hors-écran).
4. **Parallaxe** : fond hero (zoom lent), contenu hero, affiches de la galerie.
5. **Tilt 3D** des 5 rubriques services (panneaux alternés image/contenu) +
   halo radial violet qui suit la souris.
6. **Hover premium** : reflet balayé sur les boutons or, zoom + légende
   complète sur les affiches, élévation sur les cartes réseaux
   (couleurs officielles TikTok / Facebook / Instagram / WhatsApp).
7. **Lightbox** immersive : clavier (←/→/Échap), swipe tactile, compteur, légende.
8. **Compteurs** animés (80+ projets, 98%, 72h, 7j/7).
9. **Curseur personnalisé** or + halo élastique (desktop).
10. **Bandeau marquee** or défilant des 5 services.
11. **Carte interactive d'Abidjan** : 11 communes survolables, panneau au clic,
    zoom molette/boutons, glisser-déposer, marqueur siège pulsant (Plateau),
    lien Google Maps.
12. **Formulaire** : labels flottants, validation live, succès animé +
    **relais WhatsApp** avec message pré-rempli.
13. **FAB WhatsApp** dernière génération : double anneau pulsant, infobulle
    « Disponible maintenant ».
